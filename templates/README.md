# templates/

**ラベルと数字の照合に使う画像を置きます。**

**ここに本物の画像は入っていません。** 画面の解像度と UI の版ごとに違うので、
**動かす人が自分の画面から切り出します**（作りかたはリポジトリの README を見てください）。

| ファイル名 | 何の画像か |
| --- | --- |
| `label-home.png` | `ホーム` |
| `label-away.png` | `アウェイ` |
| `label-total-matches.png` | `合計マッチ数` |
| `label-goals.png` | `ゴール`（**列の見出し。`得点` ではない**） |
| `label-game-code.png` | `ゲームコード`（チーム選択画面） |
| `digit-0.png` 〜 `digit-9.png` | 数字 1 文字ずつ |
| `templates.json` | `referenceHeight`（切り出した画面の高さ） |

**照合は輝度だけで行います。** 色は関係ありません。

⚠ **余白を含めすぎないでください。** 背景ごと切ると当たりが鈍ります。

⚠ **`referenceHeight` を間違えると何も当たりません。**
`crop` が切り出しのたびに元の画面の高さを教えるので、その値にしてください。

⚠ **切り出した画像をこのリポジトリに入れないでください。**
画面には選手名が写っていることがあります。
