# templates/

**ラベルと数字の照合に使う画像。**

**2026-09-08 に実画面から切り出したもの**（1920x1080 / `referenceHeight` は 1080）。

| ファイル名 | 何の画像か |
| --- | --- |
| `label-home.png` | `ホーム` |
| `label-away.png` | `アウェイ` |
| `label-total-matches.png` | `合計マッチ数` |
| `label-goals.png` | `ゴール`（**列の見出し。`得点` ではない**） |
| `label-game-code.png` | `ゲームコード`（チーム選択画面）。**まだ無い** |
| `digit-0.png` 〜 `digit-9.png` | 数字 1 文字ずつ |
| `templates.json` | `referenceHeight`（切り出した画面の高さ） |

## ⚠ digit-4 は仮のものである

**`4` はどちらの合計マッチ数の行にも出ていなかった**ので、選手の行から取っている。

⚠ **選手の行は字が小さい**（15 画素。合計マッチ数の行は 18 画素）。
**照合が通らない見込みで、通らなければ読みが丸ごと捨てられる**（誤った値は入らない）。

**合計マッチ数の行に `4` が出ているリザルト画面を撮って、差し替えること。**
パスや得点の合計に出やすい。

## 入れてよいもの・いけないもの

| | |
| --- | --- |
| **入れてよい** | **ここにあるテンプレート。**ラベルと数字だけで、**選手名は写らない** |
| ⚠ **入れてはいけない** | **元の画面**（`captures/`）。**選手名が写る。**`.gitignore` に入れてある |

## 作りかた

**ラベル**は `crop` で切る。**数字**は目分量では切れないので `slice` を使う。

```
rematch-observer.exe slice --in result.png --rect 880,556,760,34 --out g
```

**字と字の隙間で切り分けて `g-01.png` … と並べる**ので、要るものを `digit-N.png` に改名する。
⚠ **桁区切りの `,` も 1 個に数えられる。**捨てること。

⚠ **数字は合計マッチ数の行から取る。** 選手の行は字が小さく、太さも違う。

## 直すとき

**照合は輝度だけで行う。** 色は関係ない。

⚠ **余白を含めすぎない。** 背景ごと切ると当たりが鈍る。

⚠ **`referenceHeight` を間違えると何も当たらない。**
`crop` と `slice` が切り出しのたびに元の画面の高さを教えるので、その値にする。
